# HobbyFund — Streamlit

Aplikasi pencatat reward produktivitas untuk ditukar menjadi budget hobi.

- Rp5.000 per jam produktif (proporsional per menit)
- Upload screenshot, OCR durasi, konfirmasi manual
- Catat pengeluaran hobi
- Riwayat dan ekspor CSV
- Penyimpanan cloud permanen menggunakan Supabase
- Blokir klaim screenshot identik berdasarkan SHA-256
 saat aplikasi restart. Batas penggunaan gratis Supabase/Streamlit tetap mengikuti ketentuan layanan mereka.
- Saldo saat ini adalah saldo reward yang dicatat, bukan saldo bank atau dompet digital.
