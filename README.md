# HobbyFund — Streamlit

Aplikasi pencatat reward produktivitas untuk ditukar menjadi budget hobi.

- Rp5.000 per jam produktif (proporsional per menit)
- Upload screenshot, OCR durasi, konfirmasi manual
- Catat pengeluaran hobi
- Riwayat dan ekspor CSV
- Penyimpanan cloud permanen menggunakan Supabase
- Blokir klaim screenshot identik berdasarkan SHA-256

## 1. Buat database Supabase gratis

1. Buat project di https://supabase.com/
2. Buka **SQL Editor** lalu jalankan SQL ini:

```sql
create table if not exists public.transactions (
    id bigint generated by default as identity primary key,
    created_at timestamptz not null default now(),
    kind text not null check (kind in ('activity', 'spend')),
    amount bigint not null,
    minutes integer,
    activity text not null,
    note text,
    screenshot_hash text unique,
    ocr_text text
);

alter table public.transactions enable row level security;

-- Untuk aplikasi pribadi yang memakai anon/publishable key, kebijakan ini
-- memungkinkan akses tanpa login. URL dan key tetap bukan pengganti autentikasi.
-- Jangan gunakan konfigurasi terbuka ini untuk data sensitif atau aplikasi publik.
create policy "Allow HobbyFund access"
on public.transactions
for all
to anon, authenticated
using (true)
with check (true);
```

**Keamanan:** SQL di atas memudahkan deployment demo pribadi, tetapi akses database terbuka kepada siapa pun yang mengetahui project URL dan anon key. Untuk penggunaan yang sungguh privat, tambahkan autentikasi (mis. Supabase Auth) dan batasi kebijakan RLS hanya untuk pengguna yang login. Jangan pernah menaruh `service_role` key di aplikasi Streamlit atau repositori.

3. Buka **Project Settings → API** (atau bagian API Keys di dashboard).
4. Salin Project URL dan anon/publishable key. Jangan gunakan `service_role` / secret key.

## 2. Upload ke GitHub

Buat repository baru, lalu unggah:
- `app.py`
- `requirements.txt`
- `packages.txt`

## 3. Deploy Streamlit Community Cloud

1. Buka https://share.streamlit.io/
2. Pilih repository, branch, dan `app.py`.
3. Di **Advanced settings → Secrets**, masukkan:

```toml
SUPABASE_URL = "https://PROJECT_ID.supabase.co"
SUPABASE_KEY = "SUPABASE_ANON_OR_PUBLISHABLE_KEY"
```

4. Deploy. Streamlit akan menginstal Tesseract dari `packages.txt` dan Python packages dari `requirements.txt`.

## 4. Jalankan di komputer sendiri

Pasang Tesseract OCR di sistem operasi terlebih dahulu, lalu:

```bash
pip install -r requirements.txt
streamlit run app.py
```

Kalau Tesseract tidak ada di PATH Windows, set path executable di `app.py` sebelum `run_ocr`, misalnya:

```python
pytesseract.pytesseract.tesseract_cmd = r"C:\Program Files\Tesseract-OCR\tesseract.exe"
```

## Catatan penting

- OCR bukan jaminan pembacaan benar. Periksa durasi, aktivitas, dan nominal sebelum menyetujui.
- Pencegahan duplikat memakai hash file. Screenshot yang sama persis akan ditolak, tetapi screenshot yang diedit, dipotong, atau disimpan ulang bisa memiliki hash berbeda.
- Aplikasi tidak menyimpan file gambar di database; hanya hash dan teks OCR yang disimpan.
- Riwayat dan saldo tersimpan di Supabase, jadi tidak hilang saat aplikasi restart. Batas penggunaan gratis Supabase/Streamlit tetap mengikuti ketentuan layanan mereka.
- Saldo saat ini adalah saldo reward yang dicatat, bukan saldo bank atau dompet digital.
